# Contributing

1. Read `AGENTS.md` and relevant `/docs`.
2. Take a task and confirm owner/acceptance criteria.
3. Create a feature branch or isolated worktree.
4. Avoid shared contract and migration edits without coordination.
5. Add/update tests.
6. Run documented checks.
7. Open a PR with summary, screenshots for UI changes, tests, risk, and migration notes.
8. Wait for review and required CI.
9. Update docs and task status.
10. Never merge your own agent changes automatically unless project policy explicitly allows it.
