# Roadmap

## MVP 1 — Team workspace
Auth, membership, task board, docs, comments, activity, role checks, RLS.

## MVP 2 — GitHub workflow
Repository connection, PR list, checks, verified webhooks, branch/PR references.

## MVP 3 — Local OpenCode
Pairing, companion, repository allowlist, job claim/lease, OpenCode adapter, event feed, result submission.

## MVP 4 — Safe review loop
Diff summary, checks, approvals, cancellation, failure recovery, audit trail.

## Hardening
Cross-platform tests, concurrency, accessibility, observability, deployment rehearsal, backup/recovery.

## Later
AI task planner, cost reporting where data is available, agent conflict warnings, multiple agent adapters, preview deployment.

Do not start a later phase until the previous phase has passing acceptance tests.
