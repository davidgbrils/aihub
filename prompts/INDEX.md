# DevHub AI Prompt Pack

Urutan pemakaian yang disarankan:

1. `00-MASTER-PROMPT.md` — tempel sebagai konteks utama/aturan proyek.
2. `01-SPECIFICATION-PROMPT.md` — rapikan dan validasi semua docs sebelum coding.
3. `02-FOUNDATION-PROMPT.md` — monorepo, auth, role, RLS.
4. `03-UI-TASKS-PROMPT.md` — dashboard dan task workflow.
5. `04-GITHUB-PROMPT.md` — GitHub integration.
6. `05-COMPANION-PROMPT.md` — local companion + OpenCode.
7. `06-APPROVAL-OBSERVABILITY-PROMPT.md` — approvals, audit, reliability.
8. `07-QA-RELEASE-PROMPT.md` — testing dan hardening.
9. `08-IMPLEMENTATION-AUDIT-PROMPT.md` — audit independen dan remediation.
10. `09-UI-POLISH-PROMPT.md` — polish UI.
11. `10-FINAL-HANDOFF-PROMPT.md` — handoff tim.

Jangan jalankan seluruh prompt sekaligus. Tunggu tiap tahap selesai, periksa laporan dan test, lalu lanjutkan. Semua prompt mengacu pada dokumen dalam `docs/` dan `AGENTS.md`.
